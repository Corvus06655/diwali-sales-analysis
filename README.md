
# Diwali Sales Data Analysis

This project looks at Diwali season sales data to understand customer buying patterns — based on gender, age, state, and product category.

## What I did

I started by cleaning the data — dropped a few unnecessary columns, removed null values, and fixed the data types. After that, I used Pandas and Seaborn to explore the data from different angles:

- Sales by gender
- Buying patterns by age group
- Marital status
- Sales by state/zone
- Occupation
- Product category

## Tools used

- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

## Key findings

- Female customers made the most purchases, and their overall spending was higher than male customers
- Some states and age groups showed noticeably higher order volumes

## Files

- `Diwali_Sales_Analysis.ipynb` — full analysis with code and visualizations
- `Diwali_Sales_Data.csv` — original dataset

## How to run

```bash
git clone https://github.com/Corvus06655/diwali-sales-analysis.git
cd diwali-sales-analysis
pip install pandas numpy matplotlib seaborn jupyter

```
